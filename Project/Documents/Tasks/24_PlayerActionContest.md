## 1. コンボの進み方

技の探し方は 2 段構え。
1. 押した順番そのもの（`BBY` など）が `routes` にあれば、その技を出す（特別なルート）
2. 無ければ「押したボタン × 何段目か」の基本技（B1〜B4 / Y1〜Y4 の 8 つ）を出す

→ 最初は基本技 8 つだけで 16 通りのルートが全部動く。見せたいルートだけ後から足す。

- 4 段目の次に単発を押すと 1 段目から（今と同じ）。
- 次の入力を待つ時間（プレハブの `comboWindow`）を過ぎると 1 段目に戻る。
- **先行入力**：スキの終わり際（`inputBuffer` 秒）に押した入力を覚えておき、スキが明けたら出す。

## 2. Y+B の溜め攻撃

### 2.1 同時押しの見分け方
- Y か B を押したら、**すぐ普通の攻撃の準備を始める**（待ち時間を入れない）。
- 攻撃の判定が出る前、かつ押してから `chordWindow` 秒以内にもう片方が押されたら、その攻撃を取り消して溜めに入る（取り消した段は数えない）。
- スキの間に Y と B の両方が先行入力されたら、スキ明けに溜めに入る。（2026-11-28：受付の中で両方押していれば、押した時間の差は問わない。ただし**スキが明けて技が決まるフレームに両方押していなければ溜めにしない**＝間違えて Y+B になってすぐ離した時は普通の段。`chordWindow` は判定が出る前の取り消しだけに使う）
- 段を出した後、スキが明けた瞬間に Y と B を両方押し続けていても溜めに入る（受付より早く押してしまっても、押し続ければ溜めになる。溜めを放った後は数えない）。

### 2.2 どの溜め攻撃になるか

| 出した時 | 溜め攻撃（JSON のキー） |
|---|---|
| コンボ外・1〜3 段目の途中 | 単独 `solo`（攻撃ではなく強化。§9） |
| 4 段目が B → その後のスキ・次の入力を待つ間に Y+B | B4 段目から `afterB4` |
| 4 段目が Y → 同じく | Y4 段目から `afterY4` |

### 2.3 溜め方
- 段階ごとに「上がるまでの時間 `holdTime`・技（判定のプレハブ）・威力の倍率・ゲージ・アニメ」を持つ。3 種類 × 3 段階。
- Y か B のどちらかを離した時の段階で放つ。最後の段階に着いたら自動で放つ。
- 溜めている間は他の行動（射撃・回避・近接）を禁止する（近接攻撃中と同じ扱い）。
- 溜め攻撃を放ったらコンボは 1 段目に戻る。

## 3. データ

`Resources/Json/Tuning/MeleeCombo.json`（調整値は Tuning にまとめる流儀に合わせた）。

```
inputBuffer / chordWindow / clipFade   … 先行入力の時間・同時押しとみなす時間・アニメのフェード
base.B[1..4] / base.Y[1..4]            … 基本技 { prefab, damageScale, gaugeGain, clip, clipSpeed }
routes["BBY"] など                     … 特別なルート（中身は同じ形）
charge.solo / afterB4 / afterY4        … { holdClip, levels[1..3] { holdTime, 技 } }
```

- **判定の形と時間**（出るまで・当たっている間・スキ・次を待つ時間）は今までどおりプレハブの `MeleeParams`。
- **威力の倍率**は JSON 側。攻撃力 × `damageScale` を `SpawnPlayerMelee` に渡す（エンジン側は変えない）。1 つのプレハブを威力違いで使い回せる。
- 必殺技ゲージの増え方 `gaugeGain` も技ごと（遅れて当てた時の倍率 `meleeLateRate` は StagePlay.json のまま）。
- `player.json` の `melee_w1〜4 / melee_strong` は使わなくなる（技の表に置き換え）。

## 4. アニメーション
- 技ごとに `clip`（.anim のパス）と `clipSpeed`。技を出す時に `PlayAnimation(clip, clipFade)` と `SetPlaybackSpeed(clipSpeed)` で再生。
- `clip` が空の間は今の姿勢のまま → **アニメが届く前でもコンボの作りは全部確かめられる**。
- 攻撃・溜めが終わったら `ApplyPlayerPose`（ボス戦は Stand、STG は飛ぶ姿勢）へ戻す。
- 溜めている間は `holdClip`（空なら何もしない）。

## 8. Y の技のための仕組み（2026-11-28）

Y1〜Y4（ユーザーのスケッチ）のために足した。技ごとに `MeleeCombo.json` に書く（書かなければ今までどおり）。**ビルド・実機未確認**。

| 項目 | 中身 |
|---|---|
| `hits` | 2 回目以降の判定 `{ time, prefab, damageScale }`。`time` は技の始まりからの秒。1 回目は今までどおりプレハブの startup で出る。2 回目以降のプレハブの startup は使わない（当たっている間だけ使う）。技全体の長さは主のプレハブの startup＋当たっている間＋スキなので、最後の判定まで収める |

### 8.2 近接中の移動と向き（2026-11-28 ユーザー：攻撃しながらスライドしている）
- 近接の発生〜スキ・溜めの間は、技の `motions` の区間（突進・回転・後退）のほかは**止まる**（ボス戦・STG とも）。射撃中に遅くなる `attackMoveSpeedScale` は射撃だけに残る。
- 向きは技が始まった時の向きのまま。変えられるのは `free` の区間（Y2・Y4 の回転）だけ。
- ボス戦は、技が始まった瞬間にスティックが倒れていればその方へすぐ向き直る（`StagePlayScene::OnComboAttackStarted`）。判定を出す向きもここで決め、2 回目以降の判定も同じ向き。前は照準（カメラの中央）の方へ出ていた。STG とジャスト回避の派生は始まった時の `ComputeAimBasis`。

### 8.3 ジャスト回避後の近接（2026-11-28 ユーザー：時間が長くテンポが悪い）
- 4 段の自動連撃をやめ、上＝Y4 からの溜め・右＝B4 からの溜めの**最後の段階を 1 発**放つ（`MeleeComboPart::StartChargeAttack`）。溜めのクリップは `autoChargeTime`（0.3 秒）で最後まで流れる速さ（×4）で見せてから放つ（2026-11-28 ユーザー）。
- 向き：派生の間はボスの本体の方へすぐ向き、技を出す時にも向き直る（判定もその向き。`StagePlayScene::CounterTargetYaw`）。前は回避した攻撃の持ち主へゆっくり向いていて、ボスを向かずに出ることがあった。

## 9. Y+B の強化（単独の溜め。2026-11-28 ユーザー決定）

- **考え方**：使わなくてもクリアできる。上手い人が敵の後隙に差し込むと速くクリアできる、上達で使えるようになる強さ。強化の使用を強制しない（強くしすぎてそれ前提の調整にしない）。遊んでもらってから直す。
- **出し方**：コンボ外・1〜3 段目の途中で Y+B を溜める。離した段階（3 段階目は自動）の強化が掛かる。攻撃は出さない。
- **強化中にもう一度溜める**：高い段階で放つと段階が上がり、続く時間の差分だけ延びる（1→2 で +3 秒）。低い・同じ段階なら変わらない。大きな隙に 1 段階のまま溜めて 2、3 と上げるテクニック用。3 段階の間は溜めに入れない。
- **切れた後 5 秒**は溜めに入れない（`lockout`）。入れない間の Y+B は普通の段。

| 段階 | 攻撃力（射撃・近接・支援） | 移動の速さ | ジャスト回避の受付 | 続く時間 |
|---|---|---|---|---|
| 1 | ×1.1 | ×1.075 | +0.05 秒 | 15 秒 |
| 2 | ×1.15 | ×1.09 | +0.05 秒 | 18 秒 |
| 3 | ×1.175 | ×1.1 | +0.05 秒 | 20 秒 |

- 溜まる時間は `charge.solo.levels[].holdTime`（0 / 0.6 / 1.2 秒）。強化の数値・切れた後の待ち・かける時の行動禁止 `releaseLock`（0.85 秒）・刃の色は `MeleeCombo.json` の `buff`（ImGui の「Buff」）。
- 見た目：強化中はビームの刃を赤く（`buff.bladeCoreColor / bladeEdgeColor`）。**刃の軌跡**（エフェクト、強化中でなくても出す）は後で作る：通常＝刃の色より少し明度を下げた濃い色、強化中＝赤く戦闘的な色。
- アニメ：溜め＝刃を顔の前に縦に立て、左手をかざして少しずつ深く構える（`MeleeChargeHoldSolo`）。かける時＝両腕を太ももの横へゆっくり振り払う（`MeleeChargeSolo`、0.85 秒）。
- コード：`MeleeComboPart`（`ReleaseBuff` / `UpdateBuff` / `CanCharge`、`GetBuff*`）、`StagePlayScene`（`ScaledPlayerAttack`・移動の倍率・ジャスト回避の受付・刃の色）。

## 10. RT+Y+B の大技（2026-11-28 ユーザー決定。**ビルド・実機未確認**）
- 動き（`MeleeChargeHoldBurst`＝両手で銃を正面へ構えて溜める／`MeleeBurst`＝放つ）：0.05 秒に正面へ爆発 → 反動で右回り、左足を軸に 1 回転（刃は斜めの面：右上で高く、左で低い）→ 0.65 秒に右の後ろ下まで振り切る。回る速さは「爆発直後に速く右上へ → 右上で少しゆっくり → 振り下ろしながら速く」。
- **入力**：銃のチャージが 1 段階以上ある時に RT を押すと、射撃を `chordWindow`（0.06 秒）だけ待ち、その間に Y+B がそろえば大技（`StagePlayScene::UpdateShooting` の `fireChordTimer_`）。Y+B を先に押した時は、強化の溜めに入ってすぐ（`chordWindow` 以内）に RT を押せば大技に変わる。コンボの外・次の入力を待つ間から出せる（攻撃中の割り込みは無し）。
- **威力**：押している長さで 3 段階（`charge.burst.levels`、0 / 0.6 / 1.2 秒・1.2 秒で自動で放つ）。爆発＝主のプレハブ `PlayerMeleeBurstBlast`（正面）、回転斬り＝`hits` の `PlayerMeleeBurstSpin`（全方位、0.19〜0.65 秒ずっと出ている 1 つの判定）。
- **多段**（2026-11-28 ユーザー）：回転斬りは、同じ相手に当たったらクールタイムが明けるまで当たらず、明けたらまた当たる（相手ごと。後ろへ回り込んだ敵にも当たる）。クールタイムは**実時間**で数え、ヒットストップで止めない（`GameScene::UpdateMelees` の `rehitDeltaTime`＝UI の時間）ので、敵の近くでうまく当て続けるほどヒットストップで延びた分だけ多く当たる。回数の上限は無し（強すぎたら 1 回の威力を下げるか上限を付ける）。
- **クールタイム**：溜めに入った時の銃のチャージで決め、チャージは使い切る（`IMeleeComboHost::ConsumeGunCharge`）。無し＝0.5 秒（1 回）／1 段階＝0.18 秒（ヒットストップ無しで 3 回）／2 段階＝0.09 秒（5〜6 回）（`burstRehitIntervals`）。仕組みは `SpawnPlayerMelee` の `rehitInterval`（0 以下は今までどおり 1 回だけ）。
- **スーパーアーマー**（2026-11-28 ユーザー）：溜め〜振り切りの間（`MeleeComboPart::HasSuperArmor`）は、被弾してもノックバックせず被弾のアニメも出さない（技のクリップを止めない）。ダメージは減らさない。吹き飛ばない代わりに、ボスの体（球の判定＋自機の判定の半径）の外へ水平に押し出す（`StagePlayScene::PushPlayerOutOfBoss`）。
- ヒットストップ・エフェクトは別チャットで作る（当たっているか分かりにくいのはそこで直す）。
