# 11. 低空飛行フェーズ（雲抜け → 大河 → 滝 → 谷）

シューティングパートの「雲を抜けて降下し、大河の上を低空で飛び、滝から谷へ落ちる」区間の設計。
参考はパルテナの鏡（3DS）の低空飛行（草原の間の川）と、雲を抜けた直後に水面へ垂直降下するカット。

関連: [2_StageArt.md](2_StageArt.md) / [3_EnemyPlacement.md](3_EnemyPlacement.md) / [4_StageGimmick.md](4_StageGimmick.md) / [9_CloudRendering.md](9_CloudRendering.md) / [10_WaterReflection.md](10_WaterReflection.md)

## 1. 確定事項（2026-10-06）

### A. 舞台は大河
- 海は滝で落ちる説明がつかないので**大河**にする。水は**滝へ向かって流れる**。
- 岸は草原、奥に山。

### B. 高度
- **カメラは絶対に水中に入れない**。プレイヤーは水面すれすれを飛び、波・水しぶきを出す。数値は実機で調整。
- 水しぶきの発生条件は**プレイヤーの高さ（水面からの距離）**で決める。カメラの高さではない（カメラとプレイヤーの縦のずれで「カメラは水上・自機はすれすれ」を作る）。
- 保険として `RailCameraController` で**カメラの Y を「水面＋余白」より下にしない**クランプを入れる。Catmull-Rom は 3秒/点の粗さ＋最速 70m/s 直後の引き起こしで行き過ぎる（水面を潜る）恐れがあるため。

### C. 垂直降下は「見せる区間」
- 雲を抜けた後の降下中は**敵を出さない**。雲が晴れてきれいな水面と景色を見せる。
- 敵が出ない時間を**約3秒**確保する。フォグが晴れきるのは 69秒なので、目安は **66〜72秒は Wave の `trigger_sec` を置かない**（実機で調整）。

### D. 区間の役割
| 区間 | 役割 |
|---|---|
| 低空（大河） | **障害物なし**で敵と戦う。水面から出る岩は飾り（当たり判定なし） |
| 谷 | **障害物あり＋敵**。難しいパート（[4_StageGimmick.md](4_StageGimmick.md) の主戦場） |

### 水面
- **カメラに追従する1枚**（UV はワールド座標で取る）。広さの上限を作らない。
- 波は**一方向**（タイトルの同心円とは別モード）。流れは滝へ向かう。
- **岸の近くは薄く、遠いほど濃く**。地形を手続き生成するので、同じハイトマップから**水深マップを一緒に書き出し**、水面 PS でワールド XZ から引く。
  - タイトルの水面は「水深 0.1m の床を見せる」作りなので、大河では**床を見せず水深の色で塗るモード**が必要。
- 反射は farClip 内の物をできるだけ映す。PEPPER で見て絞る。
- 水しぶきはパーティクル等のエフェクトで作る。
- 逆光は見せる所だけにするかもしれない（敵が正面にいると影になってシルエットになるため）。手段は2案:
  1. 見せる区間だけ短いセクションを挟んで太陽を逆光にする（今のセクションの仕組みのまま追加コストなし。ただし補間中に影の向きが動く）
  2. 太陽はそのまま、見せる区間だけ補助光を足す

### 地形・置く物
- Blender は使わず**手続き生成**。
- 水から出る岩は**レールの近く**に置く（近いほど速く見える）。
- 遠景の山は**板ポリ＋Y軸ビルボード＋フォグ**。
- 滝は**UVスクロールの Primitive**、霧は**Addブレンドのパーティクルで煙**。
- 岸の泡は余裕があれば。

### 空・雲
- 空と雲は**タイトルで作ったものを流用**（Skybox＋`CloudLayer`）。雲の下を飛ぶので頭上が雲で覆われているのは自然。
- レイマーチの雲（9_CloudRendering フェーズ3）は**反射させない**。雲を抜けて水面を見せている間に**レイマーチの雲は消して軽くする**。
  - **タイミング**：雲を抜けきった後（フォグが晴れきる 69秒）、カメラが水面を見下ろしたまま**もう少し降下を続ける区間**を作り、そこで消す。敵が出ない約3秒（§1-C、目安 66〜72秒）と同じ区間。雲はカメラの上か後ろにあって画面に入らず、水面にも映さないので、消えた瞬間が見えない。頭上の空には遠景の雲（`CloudLayer`）が残る。
  - **きっかけはレールの時刻**（例：70秒を過ぎたらオフ）。カメラの向きで判定するより毎回同じ結果になり、動画の撮り直しでずれない。閾値はカメラワークの調整に合わせて動くので ImGui で変えられるようにする。
  - **消し方**：0.5秒ほどで密度を下げてからパスごと止める（画面に入らない想定だが、カメラワークを変えたときの保険）。
  - **シークで巻き戻したとき**は時刻で判定し直して再びオンにする（`StageEnvironment` のセクションと同じ扱い）。
- 反射させる雲（遠景の雲 = `CloudSky.hlsli`）に**ハイトマップによる濃淡とリムライト**を足す。タイトルにも効くので**最優先**（[9_CloudRendering.md](9_CloudRendering.md) フェーズ1の拡張）。

---

### 遠景の雲のもこもこ（2026-10-07）
- `tools/Python/gen_cloud_noise.py --moko`（既定レシピ `large_soft`）→ `Resources/Textures/Cloud/cloud_moko_height.dds`（BC4・高さ）。
- 法線では持たない（エンボス調になり人工的に見えた）。高さを **密度への加算（輪郭をちぎる）／太陽方向の透過率（大きい影）／こぶの太陽側との比較（小さい影）／リム** に使い回す。式の手本は同スクリプトの `moko_render`。
- 円らしさは `lobe`（こぶを角度でいびつに）と `billow`（形を持たないうねり）で崩す。
- **既知の粗（時間があれば）**：雲の中央に暗い部分が必ず寄る（大きい影＝透過率が厚い中心ほど下がるため）。遠景用なので許容し、レイマーチを優先する。

## 2. 後回し

- **時間の細部**：実機で調整。低空区間の途中の変化（岩が増える・川幅が狭まる・滝の音が近づく等）は基礎ができてから。
- **カメラワーク**：ルートと物を置いてから。垂直降下（ピッチ −90°）→引き起こし、S字のバンク、滝への落下。
  - `EulerFromQuaternion` の特異点は yaw=±90° で、ピッチ −90° ではない。真下を向くこと自体は問題ない。
- **低空の敵の種類と配置**：Phase E。
- **性能の予算**：反射RTに入れる物の数、地形の描画数。PEPPER で実測。

## 3. 実装の章立て（1章 = 1チャット）

どう実装するかの細部は、章ごとに新しいチャットで詰める。この節は**章の分け方・順序・章の間の受け渡し**だけを決める。

### 3.0 共通の取り決め（全章が前提にする値。L0 = このファイルで管理）

**章どうしは、ここに書いた値だけで繋がる。他の章のコードの完成を待たない。**

| 項目 | 値（仮でも固定） | 根拠・備考 |
|---|---|---|
| 座標系 | +Z が前方、+Y が上（`gen_rail_path.py` と同じ） | |
| **水面の高さ** | **Y = 0** | 地面 Y=0 の前提を流用。岸の草原は Y = 0〜3m 程度 |
| 谷 | 谷底 Y = −150、谷の中の飛行 Y = −60 | 現行レール |
| **レールの XZ は動かさない** | 低空区間は X = −40〜+40 の S字、Z = 1420（66秒）〜 2500（117秒） | L4 は **Y だけ**を変える。だから L2 は今の XZ で川筋を作れる |
| 川筋 | 中心線 = レールの XZ。**半幅は 100m 以上** | レールの振れ ±40m＋自機の移動範囲＋余白。広げるのは L2 の自由 |

### 3.1 デッドロックを起こさないルール

1. **依存は §3.0 経由だけ**。前の章の成果物が無くても、§3.0 の値で作った**仮データ**で進める（例：L3 は手書きの仮の川のマップで先に作る）。
2. **§3.0 を変えたくなったら、その章では変えない**。このファイルの §3.0 を書き換えてから（L0 の作業）、影響する章に伝える。
3. **ファイルは1章が所有する**（§3.3）。他の章のファイルを直したくなったら、自分では直さず §3.4 に依頼を書く。
4. **シーン JSON（`Resources/Json/Scenes/StagePlay.json`）は キー単位で所有**。ツールは自分のキー以外を書き換えない（`CameraPath` = L4、地形・置く物のエントリ = L2/L6）。2つのツールを同時に走らせない。
5. **後ろの章から前の章へ依存を戻さない**。L8 は全章の成果を「使う」だけで、前の章の仕様を変えない（変えるなら 2. の手順）。
6. このファイルの外のチャットとの境界：
   - **水面のコード**は、タイトル用の波（チャットW）と同じファイル。**大河モードは L3 が追加する別モード**とし、タイトルの挙動を変えない。
   - **レイマーチの雲**（9_CloudRendering フェーズ3）は別チャット。L5 は「オン/オフ（フェード付き）できる」ことだけを前提にし、無ければ空の関数で先に配線する。
