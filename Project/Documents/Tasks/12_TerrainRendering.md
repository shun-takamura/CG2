## 2. 生成

### 2.1 スクリプト
- 汎用の地形生成スクリプト1本＋**レシピ JSON**（`gen_terrain_material.py` の `--recipe` と同じ流儀）。川・丘・崖はレシピで指定する。谷にも同じスクリプトを使えるようにする（§6）。
- 流れは「ハイトマップ → glTF → `cook_assets.py` → .mesh/.mat」。glTF は `gen_flagstone_floor.py` と同じく直接書く（**cook の X 反転・三角形の向きの反転・v 反転を見越して逆算する**。`gen_title_logo_plane.py` 参照）。
- 置き場所は石畳と同じ構成（`Assets/Models/<名前>/`、`Assets/Textures/...`）。ノイズの中間 PNG は `Assets/` に置かない（cook が BC7_SRGB で上書きする）。

### 2.2 メッシュ
- **2m 間隔の1枚グリッド**（約85万頂点・170万三角形。2026-10-08 に 4m から変更：岩の塊の凹凸で影を落とすため）。崖だけ細かくする必要があるかは作って見てから決める。
- UV は地形全体で 0〜1（スプラットマップ用）。層のテクスチャはシェーダでワールド XZ から取るので、UV は1本で足りる。
- 今の Object3D は視錐台カリングをしないので、チャンクに分けても軽くならない。重くなったら §7 の手段を使う。

### 2.3 形
| 部分 | 内容 |
|---|---|
| 川 | 半幅 100〜240m。**左右の岸は別のノイズ**（波長 約300m、その点の Z で引く）＋岸の線を ±80m 揺らして入り江・岬を作る（川がレールに沿いすぎて単調になるのを避ける）。**中心線から 110m 以内は必ず水**（smooth min。陸まで実測 ≥105m で §3.0 の半幅 100m 以上を守る）。水面の幅は 224〜480m（平均 約350m。2026-10-08 に「川しか見えない」ため 708m から狭めた） |
| 川底のポリゴン | **−3m で止める**。深さの色は川のマップの R が持つ（形と色を分ける。L3 の水面は床を見せないモード） |
| 岸 | 草原 Y = 1〜4m。岸辺は急な斜面（川底まで約30m）で、低い段差の岸に見せる |
| 外側 | X = ±1000 に向かって低い丘（〜60m。fBm）。奥の山は L6 の板ポリ |
| 滝の手前の丘 | 川の半幅の外側、Z ≈ 2100〜2500 の両岸。斜め前の視線を切り、谷の左右を隠す（L9 の谷のロード用）。**形はパルテナの「草の斜面の途中に岩の崖が段になって出る丘」**：高さ 80〜120m、尾根のノイズ（ridged）で尾根筋を出し、高さを段にする（テラス）と段の境が急斜面＝岩の層になる。丘の上は少し平ら |
| 丘の起伏 | 外側の丘にも尾根・テラスを混ぜ、陸の上全体に細かい起伏（波長 50〜80m・数 m）を足す。つるっとした輪郭を崩す（2026-10-08、Step 1 の実機確認で「ローポリ感」の指摘） |
| 崖 | 台地の縁は Z ≈ 2500〜2540、リッジノイズでギザギザに。谷底 Y = −150 まで落とす。川が流れ落ちる所は縁を少し掘り下げて「滝の口」にする |
| ⚠️ 崖とレール | **レールが通る X ±40 付近では縁を Z ≤ 2540 に収める**（idx40 は Z=2565・Y=−10 で台地より下を通る） |

## 3. 地形専用シェーダ

### 3.1 構成
- `ShaderType` に **`kShaderTerrain`** を足し、`.mat` の `shadingModel = 2` で選ぶ（`Object3DInstance` の PSO 選択、`DrawReflection` の分岐にも足す）。
- ルートシグネチャは Object3D のものを使い回す（Fog・Shadow・Cloud の配線がそのまま効く）。**末尾にルートパラメータ 16（t6）・17（t7）を足す**。既存のインデックスは動かさない。
- PBR の式（`Object3dPBR.PS.hlsl` の GGX などの関数）は**共通の .hlsli に切り出して**両方から使う。Shadow / Fog / CloudSky は既に .hlsli なので include するだけ。
- ⚠️ `AnimatedObject3DInstance` などルートシグネチャを貼り直す経路があるので、地形の描画の前に t6/t7 が貼られていることを確認する（Fog の `BindFog` で踏んだ罠と同じ）。

### 3.2 テクスチャ
| レジスタ | 中身 | 備考 |
|---|---|---|
| t0 | **スプラットマップ** 2048²（約1m/texel） | R = 草、G = 土/砂（岸辺）、B = 岩（急斜面・崖）、A = 濡れ（水際を暗く）。UV で引く |
| t6 | **層の色の配列**（3枚。A = 高さブレンド用の高さ） | ワールド XZ でタイル。BC7 |
| t7 | **層の法線の配列**（3枚） | パスに `NormalMap` を入れて線形で圧縮 |

- 層の素材は `gen_terrain_material.py` で作る（色の A に高さを入れるよう拡張する）。
- **配列テクスチャの対応状況（2026-10-08 調査）**：資源の作成は FS 経路（`SpriteManager.cpp:249`）・DirectStorage 経路（`TextureManager.cpp:504`）とも arraySize 対応済み、pack も配列を扱える（`pack_assets.py:142-146`）。**足りないのは SRV だけ**で、キューブでない配列は `CreateSRVForTexture2D` に落ちて1枚目しか見えない → `SRVManager` に `CreateSRVForTexture2DArray` を足して分岐する。
- 配列の DDS は texassemble が無いので、各層の BC7 DDS（同じ大きさ・同じミップ数）を Python で **DX10 ヘッダの配列 DDS に結合**する。

### 3.3 .mat v5
v3（法線）→ v4（視差）と同じ伸ばし方で **v5** に層の情報を足す。
- 層の色の配列のパス、層の法線の配列のパス
- 層ごとのタイル長[m]、粗さ（3つずつ）、高さブレンドの鋭さ
- cook は glTF の extras から書く（視差の `extras.heightTexture` と同じ前例）。
- `Material` の CB は今 192B。256B 単位で確保しているので、足しても確保量は変わらない（`static_assert` と HLSL 側のレイアウトを合わせて更新する）。

### 3.4 塗り方
- **高さブレンド**：スプラットの重み × 各層の高さで境界を噛み合わせる（線形に混ぜるとぼやける）。
- **繰り返し模様**：2スケールのサンプル＋低い周波数の色ムラ。ストキャスティック・タイリングは使わない（重い）。
- **三平面投影は岩の層だけ**（崖・急斜面が XZ 投影だと縦に引き伸びるため）。草と土は XZ 投影1回。
- **法線の合成は whiteout**。層は XZ 投影なので接線 = ワールド X、従法線 = ワールド Z に固定でき、頂点の tangent は要らない。
- 草と土は粗さ高め。鏡面反射・雲の映り込み（`cloudReflection`）は 0。
- **草は層のテクスチャだけで表現する（ジオメトリなし）**。木立・茂みは L10（11 番）がインスタンス描画で置く。

## 4. 水面への映り込み

- `kShaderTerrain` を足せば、反射用の PSO（`reflectionPipelineStates_`）も同じ仕組みで作られる（`CreateGraphicsPipelineState(..., forReflection=true)`）。`DrawReflection` に `shadingModel == 2` の分岐を足すだけで、地形の PS がそのまま鏡側で動く。
- **何を反射 RT に入れるかは L3（水面）の所有**。地形を反射の対象にしてもらう依頼は 11 番 §3.4 に書く。
- 鏡側では地形の大半が水面より下（川底）なので、**クリップ面（Y=0）より下は描かない**ことを L3 と確認する。
- 重さは §7 と同じく、フレームが落ちてから PEPPER で見る。

## 6. 谷への流用

**左右の谷壁の大まかな形は、同じスクリプトでレシピを変えれば作れる。**

- 川の代わりに「レールに沿って掘る溝」として扱う：谷のレール（idx41〜59、Z = 2605〜3505、X ±33）を中心線にして、谷底 Y = −150・壁の上端 Y ≈ 0 の溝を掘る。滝の崖と同じリッジノイズで壁の線をギザギザにする。
- 塗りは同じ地形シェーダで、ほぼ岩の層だけ（三平面投影が効く）。
- **ハイトマップの限界**：
  - **オーバーハング（せり出し）や洞窟は作れない**（1つの XZ に高さ1つ）。
  - 4m 間隔だと、ほぼ垂直の壁は三角形が縦に引き伸びる。ノイズで壁の線を水平方向に揺らして平らな面に見えないようにし、細部は三平面投影の岩の法線で出す。それでも足りなければ、壁の近くだけ細かくする。
- **岩肌の凹凸・石柱は別のモデル**として置く（谷の担当。当たり判定もそちら）。
- 谷に適用するかどうかは谷の担当が決める。L2 は「レシピを変えれば作れる」作りにしておくところまで。

## 7. 性能（重くなったら）

予算は設けない。フレームが落ちたら PEPPER で地形の区間を見て、次の順で考える。
1. 遠くの地形をまばらにする（LOD）／チャンクに分けて視錐台カリングを入れる
2. 反射 RT に入れる範囲を絞る（L3 と相談）
3. 三平面投影・2スケールのサンプル数を減らす
4. 影のカスケードの比率（`SetCascadeLambda`）の調整。CSM は 2048²×3段で、遠くの影が粗いのは許容する
