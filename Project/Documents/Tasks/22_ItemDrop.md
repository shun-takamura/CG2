## 1. アイテム

天球儀の古代機械という世界観に合わせた。見た目はプリミティブのプレハブ（加算・当たり判定なし）。

| id | 名前 | 見た目（プレハブ） | 主に落とす敵 |
|---|---|---|---|
| Cog | 天輪の歯車 | 金のリング（`loot_cog`） | ドローン |
| StarShard | 星晶のかけら | 水色の四角すい（`loot_shard`） | ホバー・突進・砲台 |
| AstralCore | 天球の核 | 白金の球（`loot_core`） | 輸送機・ボス（必ず） |
| （Ether） | エーテル | 水色の球（`loot_ether`） | 全部の敵 |

### 1.1 ドロップ表（仮の値）

| 敵（プレハブ） | エーテル | 素材 |
|---|---|---|
| drone | 5 | 歯車 40% |
| HoverEnemy / rusher / turret | 15 | 星晶 50%・歯車 30% |
| carrier | 40 | 核 1・星晶 2（必ず） |
| ボス | 300 | 核 3・星晶 5（必ず。撃破でそのまま集計へ） |

- 谷の岩・梁（enemy_type "Obstacle"）は落とさない
- エーテルには難易度の報酬倍率（`DifficultyProfile::GetRewardScale`、今は 1.0）を掛ける
- 1 周でおよそ 歯車 13・星晶 17・核 5・エーテル 800

## 2. 落ち方と拾い方

1. 倒した所から上向きに弾ける（0.3 秒、勢いは指数で落ちる）
2. 自機へ加速しながら寄る（残りの距離が exp(−rate) で縮み、rate は時間で上がる。最低の速さも持つ）
3. 自機の 0.8m 以内で獲得 → 集計へ。3 秒たったら届いていなくても獲得
- 位置は「自機から見たずれ」で持つので、レールで自機が進んでも置いていかれない
- エーテルは 1 体につき 1 粒にまとめ、素材は 1 個ずつ落とす（右下の数が増えて見える）
- 同時に落ちている数の上限 48（越えた分はすぐ獲得）。レールを抜けるとき残りは全部獲得、シークでは拾わずに消す

## 3. 拾ったときの表示（右下）

- 「天輪の歯車 ×3」「エーテル +45」の行を下から積む（最大 5 行）。左にアイテムの色の縦線と印
- 同じ物を続けて拾ったら行を足さず数を増やし、数を少し弾ませる。2 秒で右へ抜けて消える。時間は実時間

## 4. クリア画面（リザルト）

- スコア・撃破数の下に「獲得した報酬」：素材 3 種（0 個の物も薄く出す）→ 区切り → エーテルの合計
- 行ごとに 0.25 秒ずらして出て、0.6 秒で数え上がる。決定で数え上げを飛ばし、もう一度でステージ選択へ
- ボス戦からのリトライで来たときは、その回（ボス戦）の分だけ

## 6. 実装（2026-11-09、ビルド・実機は未確認）

| ファイル | 役目 |
|---|---|
| `Resources/Json/Tuning/Loot.json` | アイテムの定義・敵ごとのドロップ表・ボスの報酬・落ち方の数字 |
| `Resources/Json/Tuning/Crafting.json` | 装備ごとの作成・強化に要る物 |
| `Resources/Json/Prefabs/loot_{cog,shard,core,ether}.json` | 落ちている間の見た目 |
| `Game/Score/LootCatalog` | Loot.json を読む（画面・落とす側は JSON を読まずここを呼ぶ） |
| `Game/Score/CraftingCatalog` | Crafting.json を読む（`FindMainWeapon` / `FindShield` / `FindFlightUnit(名前, 段階)`） |
| `Game/Score/LootLedger` | そのステージの獲得の集計（シングルトン）。`Add`・`AddBossReward`・最近拾った物の列（`PopPickup`）。Debug の ImGui「Loot (22)」で足す・リセット・Loot.json の読み直し |
| `Game/Scene/Loot/LootDrops` | 落とす・吸い寄せる・拾う。`ObstacleDebris` と同じく `RailStagePart` が持ち、`ILootDropsHost` 経由で見た目を出し入れする |
| `Game/Scene/Loot/LootPickupLog` | 右下の表示。`StagePlayScene` が持つ |

- 撃破の口：`RailStagePart::UpdateWaveAndEnemies` の撃破検出（Wave のプレハブ名で表を引く）
- `StagePlayScene` の変更：開始で集計をリセット・レールを抜けるとき `CollectAllLoot`・ボス撃破で `AddBossReward`・表示の Update と Draw（スコアと同じ Flush）・落とし物をシーンの保存から外す
- `ResultScene`：獲得した報酬の表示。`LoadoutScreen`：`ItemCost` / `DrawCost`
