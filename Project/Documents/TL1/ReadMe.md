# 加点項目

* ローダーと配置
* コライダーをゲーム側当たり判定に適用
* ホットリロード（ゲーム側）
* SpawnPoint（敵などの発生地点）の配置
* カメラの配置
* 敵の巡回ルートを配置
* Terrain（地形）の配置

# 独自実装

* Blender を自作エンジンのレベルエディタとして使えるようにした連携パイプライン
    * Blender で地形・プロップ・スプライン・カメラパスを配置し、1 ボタンで変換からゲームへの反映まで自動実行できる
    * Blender で動かした結果が 0.3 秒ほどでゲーム画面に反映され、エンジンのギズモで動かした結果も Blender へ戻る（双方向）
    * 共有ハッシュ 1 つで「相手の書き込みを読み返して延々と往復する」反響を止めており、書き込みは一時ファイル＋リネームで原子的に行うため書きかけの JSON を掴まない
    * glTF はカーブを運べず Blender が制御点を書き出さないため、点列を自前でワールド座標へ変換して受け渡し、往復しても制御点の誤差 0.0 を実測している
    * 回転行列の合成順が 2 種類あるため、実際に配置へ使われる順に合わせて変換し、Blender とゲームで位置・回転が一致するようにした
    * 固定砲台は Blender のエンプティに出現時刻を持たせて敵定義（Wave JSON）へ書き出すので、地形と敵を同じ画面で配置できる
    * 上書き前に必ず .bak を退避し、非 ASCII のオブジェクト名は自動で正規化してエンジンが読めない名前を作らない
    * レベルアートは使い慣れた Blender、ゲームプレイの詰めは実機、と道具を役割で分けている
* 敵ウェーブ配置エディタ（インエンジン）
    * タイムラインを任意の秒までスクラブし、その瞬間のレールカメラ越しにプレハブをドロップするだけで、敵の出現時刻と画面内の位置が決まる
    * 画面に対して静止して見える敵はワールド座標では表現できないため、ドロップ位置をカメラ基準のオフセットへ逆変換して保存している
    * 敵の定義はシーン JSON と別系統の Wave JSON に置き、プレイ中の敵の移動が配置データに焼き付かないようにしている
* エフェクトエディタ
    * パーティクルとプリミティブのパラメータを GUI で編集でき、保存すると起動中のゲームへ再起動なしで反映される
    * プレビューはシーンの時間倍率を通さない専用クロックで動くため、ヒットストップや必殺技で世界を止めている最中でも編集を続けられる
* アセットコンバータ ＆ パッケージャ（DirectStorage 対応）
    * Assets フォルダに素材を置いてビルドするだけで、PNG → DDS・OBJ/glTF → .mesh/.mat/.skel/.anim へ自動変換され、1 つの .pack にまとまる
    * GDeflate で圧縮したまま DirectStorage 1.4 で GPU へ送って展開するため、CPU を経由せずに読み込める
    * 法線マップの有無を見て PBR シェーダーへ自動で切り替えるので、変換設定を手で書く必要がない
* P.E.P.P.E.R.（自作プロファイラ）
    * ゲーム内オーバーレイで CPU/GPU の区間時間・ドローコール数・VRAM 使用量を毎秒確認でき、ログから最も遅い区間を file:line 付きで一覧できる
    * 計測はログを書くだけでゲームの乱数や経過時間に触れないため、後述の自動検証の決定論リプレイと同時に動かせる
* S.U.N.D.A.Y.（無人自動検証システム）
    * 人が寝ている間に仮想ゲームパッドでゲームを自動プレイし、ハング・スタック・座標の破綻・クラッシュを検知して GitHub の Issue に自動で起票できる
    * 乱数シードと毎フレームの生入力を記録する決定論リプレイを持ち、検知した不具合が本当に再現するか自動判定してから起票するので、再現しない報告が積み上がらない
* MediaPipe モーションキャプチャツール
    * Web カメラや動画ファイルから人の動きを取り込み、glTF または エンジン形式（.skel / .anim）として書き出してそのまま再生できる
    * 既存モデルへのリターゲットに対応し、Blender アドオン版では Blender の中だけでキャプチャからリターゲットまで完結する
    * モーキャプは全フレームにキーが乗って手直しできないため、クォータニオンを球面補間の角度誤差で評価する RDP 法でキーを約 1/3 に削減できる
* J.A.R.V.I.S.（リモート開発環境）
    * 外出先のスマホのブラウザから、自宅 PC のビルド・AI によるコード編集・push・画面配信・ゲームの遠隔操作ができる
    * 自作の Web コンソールなので外部サービスの仕様変更に左右されず、入力から表示までの遅延を自前で計測できる
